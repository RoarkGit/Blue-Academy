### Act 1

This stage is notoriously difficult for a lot of people and is probably the
hardest stage we've seen up to this point. It is the first stage where we
_actually_ need to respect mechanics! Our main target is the Bestial Node, but
it will spawn a Shabti shortly into the fight. The Shabti starts with a very
strong damage up buff which lasts for 20 seconds. When it has this buff, it will
one-shot us. The Shabti is vulnerable to sleep, so we can use
{{< action sleep >}} to disable it for 30 seconds. Once the debuff falls off we
need to kill it, though, since eventually it will enrage and kill us! While
we're waiting for the buff to fall off we still need to kill the Bestial Node.
It uses a line AOE called Piercing Laser, a point-blank AOE called Repelling
Cannons, a donut AOE called Superstorm, and Ballast which is a 270-degree
Plaincracker-style AOE which we can avoid by stepping inwards after an AOE or by
going behind the node. High Voltage is an unavoidable AOE that causes Paralysis,
but it can be interrupted with {{< spell flying_sardine >}}. Eventually two
Serpents will spawn that need to be killed. When they die they apply a
vulnerability stack to all nearby targets, including the Bestial Node.

The Shabti spawn can be skipped if you have sufficient damage. A
{{% relref "/gameplay/moon-flute-opener" %}} will do this quite easily, but make
sure to interrupt the early High Voltage cast!
