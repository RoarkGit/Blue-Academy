## Blue Mage Reference Tools & Calculators

This section contains reference data, planning tools, and calculators
designed to help you optimize your Blue Mage setup and understand spell
mechanics.

### Interactive Tools

The tools below provide real-time calculations and planning capabilities to
help you build effective spell loadouts. New to Blue Mage? Start with our
[Getting Started]({{% relref "/getting-started/" %}}) guide first.

- **[Spell Loadout Builder](/resources-and-tools/spell-loadout-builder/)** -
  Create and customize Blue Mage loadouts for different content. Filter spells
  by type, aspect, and status effects to build the perfect setup. Learn more
  about role strategies in our [Gameplay guides]({{% relref "/gameplay/" %}})

- **[Spell List](/resources-and-tools/spell-list/)** - Complete searchable
  reference of all Blue Mage spells with properties and learning locations.
  Filter by type, aspect, rank, target type, and status.

- **[Final Sting Calculator](/resources-and-tools/final-sting-calculator/)** -
  Calculate Final Sting damage based on party composition. Understand how many
  stings you need to finish off bosses.

- **[DPS Simulator](/resources-and-tools/dps-sim/)** - Analyze theoretical
  damage output for different spell rotations and strategies in various
  scenarios.

### Reference Data

- **[Damage Formula](/resources-and-tools/damage-formula/)** - Technical
  breakdown of how Blue Mage damage is calculated. Understand the mechanics
  behind weapon damage, ability power, and stat scaling.

- **[Death Vulnerability](/resources-and-tools/death-vulnerability/)** - List
  of bosses in each dungeon that are vulnerable to death spells.

Data is regularly updated to reflect the latest balance changes and content
releases.
